# 📜 Правила войн

Правила действуют с момента, когда **вы объявили войну или её объявили вам**, и до её конца —
включая оправдание. Как устроена сама война, описано на странице [Войны](war.md); общие правила
сервера — в [Правилах](rules.md).

!!! warning "Права администрации"
    Администрация вправе **остановить войну** при нарушении правил, если это предусмотрено
    наказанием, а также **ликвидировать нарушение** на своё усмотрение.

## Коротко

| № | Нарушение | Наказание |
|---|---|---|
| [2](#r2) | Махинации со своим городом после объявления войны | <span class="nak">бан 1–7 дней</span> |
| [3](#r3) | Слив очков — умышленно поддаваться противнику | <span class="nak">бан 3–7 дней</span> |
| [4](#r4) | Приваты других городов со стратегическими целями | <span class="nak">бан 3 дня, перенос центрального чанка или расприват</span> |
| [5](#r5) | Война против новичков и городов младше двух недель | <span class="nak">бан мэра 24 часа и остановка войны</span> |
| [6](#r6) | Помеха от игроков, не участвующих в войне | <span class="nak">бан 7 дней</span> |
| [7](#r7) | Лазейки в правилах и баги ради победы | <span class="nak">по решению администрации</span> |

## 🏚 2. Махинации с городом { #r2 }

Когда вы объявили войну или её объявили вам, **запрещено**:

| № | Запрещено | Уточнение |
|---|---|---|
| 2.1 🔒 | Удалять свой город, на который напали | |
| 2.2 🔒 | Перепривачивать территорию своего города, на который напали | удалять старый приват, заменяя его приватом другого города или не заменяя вовсе. **Приватить новые чанки можно** |
| 2.3 | Объединять города во время оправдания войны | |
| 2.4 🔒 | Снимать монеты с города | исключение — монеты на прокачку `/t builds` этого же города |
| 2.5 🔒 | Переименовывать город | |
| 2.6 | Ставить типы чанков, мешающие установке флагов | караются любые махинации с чанками через плагин ради того, чтобы флаг нельзя было поставить |
| 2.7 🔒 | Выключать PvP на территории нападающего и защищающегося города | |
| 2.8 🔒 | Переносить центральный чанк города во время войны | во время оправдания — можно |

🔒 — сервер сам не даст это сделать (`/t delete`, `/t unclaim`, `/t outpost remove`, `/t withdraw`, `/t set name`, `/t toggle pvp`, `/t setspawn` с начала боя заблокированы). Остальное проверяет администрация.

**Наказание:** <span class="nak">бан от 1 до 7 дней</span>

## 🎭 3. Слив очков { #r3 }

Запрещено сливать очки во время войны — **умышленно поддаваться противнику**.

**Наказание:** <span class="nak">бан от 3 до 7 дней</span>

---

## 🗺 4. Стратегические приваты { #r4 }

Запрещены любые приваты **других городов**, сделанные со стратегической целью. В зоне боевых
действий — приват только двух городов: **нападающего и обороняющегося**.

??? example "Примеры нарушений"
    - Обпривачивать центральный чанк твинк-городом, чтобы создать неприступные укрепления
      на подходе к нему.
    - Делать плацдармы для наступления с твинк-городов, чтобы и они были неприступны.
    - Всё в этом духе — тоже запрещено.

??? note "Примечание: соседний город — не нарушение"
    Если приват просто прилегает к укреплениям и очевидно сделан без стратегической цели
    (обычный город по соседству), наказания не будет.

    Но если вы **целенаправленно используете** соседний город, рассчитывая, что его приват
    облегчит вашу **оборону**, — последует наказание.

**Наказание:** <span class="nak">бан 3 дня, перенос центрального чанка или расприват</span>

---

## 🐣 5. Война против новичков { #r5 }

Запрещено объявлять войну **новичкам** и **городам, которые существуют меньше двух недель**.

???+ tip "Исключение"
    Город или новичок проявляет агрессию в сторону вашего города или напал первым.

!!! info "🔒 Проверяет сервер"
    Город младше 14 дней не появится целью: объявление откажет, если только он сам не объявлял
    вам войну за эти дни. Агрессию без войны оценивает администрация — пишите ей.

**Наказание:** <span class="nak">бан мэра на 24 часа и остановка войны</span>

---

## 🚷 6. Помеха со стороны { #r6 }

Игрокам, которые прямо не участвуют в войне, запрещено **мешать в зоне боевых действий**.
Не участвуют — те, кто не состоит в воюющем городе и не в альянсе с ним.

??? note "Примечание 1: вар-склады — тоже зона боевых действий"
    Например, нельзя пытаться подобрать ресурсы, которые выдаются игрокам на вар-складе.

??? note "Примечание 2: союзник — не исключение"
    То, что игрок ваш союзник, ещё не даёт ему права нарушать это правило. Хотите, чтобы он
    воевал, — пригласите его в воюющий город, и он станет участником войны.

**Наказание:** <span class="nak">бан 7 дней</span>

## 🐞 7. Лазейки и баги { #r7 }

Запрещено целенаправленно использовать во время войны **очевидные лазейки, недосказанности
в правилах и баги**.

!!! tip "Нашли недочёт?"
    Сообщите администрации в [Discord проекта](https://discord.gg/nationrise). Абузить баг
    ради победы нельзя.

**Наказание:** <span class="nak">по решению администрации</span>
