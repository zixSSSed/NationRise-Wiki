# Кастомные крафты

Часть предметов не собирается в обычном верстаке — для них есть своё окно:

```
/crafts
```

Внутри: **Верстак** (там собираются предметы), **Рецепты миньонов** (справочник по всем
видам), **Звезда Незера** и вкладка **Военное** — флаги захвата и защиты и штурмовой
динамит для [войн](war.md) с быстрым крафтом прямо из инвентаря.

!!! tip "Рецепт можно посмотреть, не выходя из игры"
    В справочнике каждый рецепт показан прямо сеткой 3×3 — видно, что и в каком
    количестве класть. Оттуда ничего нельзя забрать, это только показ.

---

## Звезда Незера

Нужна для **6 уровня города** (три штуки) и **7 уровня** (шесть). Иссушитель даёт её и сам,
но собрать бывает проще, чем убить девять боссов.

|  |  |  |
|:---:|:---:|:---:|
| Обсидиан ×32 | Синее стекло ×8 | Обсидиан ×32 |
| **Голубое стекло ×8** | **Золотой блок ×8** | **Голубое стекло ×8** |
| Обсидиан ×32 | Синее стекло ×8 | Обсидиан ×32 |

Итого на одну звезду: **128 обсидиана**, **16 синего стекла**,
**16 голубого стекла**, **8 золотых блоков**.

Здание для этого не нужно — звезда доступна любому игроку.

## Миньоны

Общий рецепт: **4 угла** — блок ресурса, **4 ребра** — он же, **центр** — инструмент.
Инструмент задаёт, к какой группе относится миньон. Подходит только **целый железный**
инструмент — без единицы урона; деревянный, каменный или побитый железный крафт не примет.

| Инструмент в центре | Какие миньоны |
|---|---|
| Железная кирка | руды, камень, незерит |
| Железный топор | все породы дерева |
| Железная мотыга | фермерские |
| Железная лопата | земляные |

!!! note "Дерево — один рецепт на девять пород"
    В справочнике порода в сетке **меняется сама** по кругу: дуб, ель, берёза,
    тропическое, акация, тёмный дуб, мангр, вишня, бледный дуб.
    Это значит, что рецепт один и тот же — **какую породу положите, такой миньон и получится**.

Для крафта миньона нужно здание **Цех миньонов**. Точные количества по каждому
виду смотрите в справочнике `/crafts` — там же указано, из чего нужна площадка 5×5.

Подробно про установку, прокачку и лимиты — на странице [Миньоны](minions.md).

## Другие особые предметы

| Предмет | Как получить |
|---|---|
| **Лассо** (3 уровня) | обычный верстак, рецепт с поводком и блоком металла |
| **Незеритовый слиток** | слиток + древние обломки |
| **Булава** | обычный рецепт, но на сервере может существовать **только одна** |
| **Книги чар** | не крафтятся — только в `/shop` за райзики |
