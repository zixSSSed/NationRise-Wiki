# Нации

Нация — это союз городов под одним флагом, со столицей, общей дипломатией и общими войнами.

## Создание

```
/n create <название>
```

Стоит **50 монет** из банка города-столицы. Нужен построенный **Дворец нации**.
Город, который основал нацию, становится столицей — на карте BlueMap он помечен короной.

## Вступление и выход

```
/n invite <город>     пригласить город (лидер нации)
/n join <нация>       принять приглашение (мэр города)
/n leave              выйти из нации (мэр города)
/n kick <город>       исключить город (лидер)
```

## Управление

| Команда | Что делает |
|---|---|
| `/n` | меню нации |
| `/n info` | сводка: столица, города, союзы, войны |
| `/n rename <имя>` | переименовать (50 монет) |
| `/n color <hex>` | цвет нации в чате, табе и на карте |
| `/n capital <город>` | сменить столицу |
| `/nc <текст>` | чат нации |
| `/n fly` | полёт по всей территории нации (ранг Октавиан) |

Цвет нации подставляется в чат перед названием города — так видно, кто с кем.

## Дипломатия

Ведётся через здание **Дипмиссия**.

**Пакты о ненападении.** Города предлагают друг другу пакт; пока он в силе, война невозможна.

**Альянсы.** Союзные нации не могут воевать друг с другом и видят друг друга как своих
в PvP-проверках.

**Враги.** Объявление вражды открывает PvP между членами наций **вне городов**.

!!! warning "PvP между городами без наций"
    Флаг «враг» работает на уровне **наций**. Два города без наций могут воевать
    только через [объявление войны](war.md) — вражды между ними не бывает.

## Санкции

Нация может наложить на чужой город экономические санкции:

- **запрет торговли** — их жители не могут покупать ваши лоты на аукционе
- прочие ограничения по договорённости

Смотреть свои: `/t` → «Санкции».

## Дань

Побеждённый в войне город может стать **марионеткой** и платить дань победителю —
**0.5 монеты в день** с города. Марионетка сохраняет мэра и территорию, но кормит сюзерена.

Подробно: [Войны → Исходы](war.md#исходы-войны).

## Что даёт нация

- общий чат и координация
- совместные войны — союзники подключаются к вашим боям
- престиж и место на карте
- `/n fly` для Октавианов — полёт по всей территории нации
- дипломатический вес: с большой нацией меньше желающих связываться
