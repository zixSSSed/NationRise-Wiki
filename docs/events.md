# Ивенты

Всё расписание в одном меню:

```
/ivents
```

Время везде — **московское**.

## Боссы

**Когда:** 10:30, 13:30, 15:00, 19:30, 21:45
**Сколько длится:** до 10 минут, потом уходит

Появляется случайный босс. Награда — **топ-3 по нанесённому урону**:

| Место | Райзики | Монеты |
|---|---|---|
| 1 | 30 | 50 |
| 2 | 15 | 25 |
| 3 | 7 | 10 |

### Кто бывает

- **Адское Отродье** — ифрит на 500 HP. Стреляет усиленными огненными шарами
  (8 урона сквозь незерит), оставляет огненный след при рывке.
- **Мутант-Крипер** — прыгает и взрывается при приземлении (14 урона).
- **Аквамен** — утопленник с трезубцем, 890 HP. Трезубец бьёт на 35 сырого урона —
  броня спасает, но чувствительно.

Боссы бьют **сквозь броню**: урон рассчитан так, чтобы фулл-незерит не делал бой скучным.

## Король горы (KOTH)

**Когда:** 11:00, 14:00, 17:00, 21:00
**Сколько длится:** 15 минут

Плагин строит купол-гору в случайной точке карты. Кто дольше удерживает вершину — забирает
награду. Классическая мясорубка: наверху всегда PvP.

## Лут-ивент

**Когда:** 12:00, 16:00, 20:00
**Сколько длится:** 30 минут

На арене появляются сундуки с лутом. Залутали — через **5 минут** сундук наполняется заново
(3–6 стопок). Вокруг сундуков жарко: все идут за одним и тем же.

## Королевская битва

Отдельная карта, отдельный мир.

```
/kb          вступить / выйти / статус
/nrparty     собрать команду (до 3 человек)
```

Инвентарь на входе **сохраняется** и возвращается на выходе — своё не потеряете.
Зона сжимается, последний выживший (или команда) побеждает.

## TNT Run

```
/tntrun
```

Исчезающая платформа: блоки пропадают под ногами. Кто дольше не упал — победил.

## Build Battle

```
/bb
```

Показывают постройку, вы копируете её **по памяти**. Награда за точность —
30 / 15 / 7 монет за первые три места.

## Час PvP

**Когда:** 23:00, длится час.

PvP включается **по всей карте**, включая территории городов. Спавн не затрагивается.
Хорошее время для набегов и плохое — для одиночных вылазок с ценным инвентарём.

## Рыбацкие турниры
