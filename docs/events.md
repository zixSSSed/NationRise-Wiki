# Ивенты

Всё расписание в одном меню:

```
/ivents
```

Время везде — **московское**.

## Боссы

**Когда:** 00:30, 03:00, 07:30, 10:30, 13:30, 15:00, 19:30, 21:45
**Сколько длится:** до 10 минут, потом уходит

Появляется случайный босс. Награда — **топ-3 по нанесённому урону**:

| Место | Райзики | Монеты |
|---|---|---|
| 1 | 30 | 50 |
| 2 | 15 | 25 |
| 3 | 7 | 10 |

### Кто бывает

- **Адское Отродье** — ифрит на 500 HP. Стреляет усиленными огненными шарами
  (8 урона сквозь незерит), оставляет огненный след при рывке.
- **Мутант-Крипер** — прыгает и взрывается при приземлении (14 урона).
- **Аквамен** — утопленник с трезубцем, 890 HP. Трезубец бьёт на 35 сырого урона —
  броня спасает, но чувствительно.

Боссы бьют **сквозь броню**: урон рассчитан так, чтобы фулл-незерит не делал бой скучным.

## Король горы (KOTH)

**Когда:** 01:30, 06:15, 11:00, 14:00, 17:00, 21:00
**Сколько длится:** 15 минут

Плагин строит купол-гору в случайной точке карты. Кто дольше удерживает вершину — забирает
награду. Классическая мясорубка: наверху всегда PvP.

Гору не нужно искать вслепую: пока ивент идёт, вверху экрана висит полоса с **координатами
вершины**, расстоянием до неё лично от вас, числом людей наверху и таймером. Те же координаты
лежат в `/ivents` на карточке ивента.

## Лут-ивент

**Когда:** 02:15, 06:45, 12:00, 16:00, 20:30
**Сколько длится:** 30 минут

На арене появляются сундуки с лутом. Залутали — через **5 минут** сундук наполняется заново
(3–6 стопок). Вокруг сундуков жарко: все идут за одним и тем же.

## Королевская битва

Отдельная карта, отдельный мир.

```
/kb          вступить / выйти / статус
/nrparty     собрать команду (до 3 человек)
```

Инвентарь на входе **сохраняется** и возвращается на выходе — своё не потеряете.
Зона сжимается, последний выживший (или команда) побеждает.

## TNT Run

```
/tntrun
```

Исчезающая платформа: блоки пропадают под ногами. Кто дольше не упал — победил.

## Build Battle

```
/bb
```

Показывают постройку, вы копируете её **по памяти**. Награда за точность —
30 / 15 / 7 монет за первые три места.

## Горячая картошка

```
/potato
```

Одна тикающая бомба на всю арену. У кого она в руках — тот и горит: подойдите
к другому участнику и **кликните по нему любой кнопкой**, чтобы спихнуть бомбу ему.

Фитиль догорел — держащий вылетает, а бомба сразу уходит к случайному из оставшихся.
Последний выживший побеждает.

- длина фитиля **каждый раз разная** — высчитать безопасный момент не выйдет
- передача работает только вблизи, бросить бомбу на землю нельзя
- сразу отдать её обратно тому, кто вам её вручил, тоже не получится
- на арене не бьют и не умирают — выбывают только по фитилю

## Свои матчи для пати

TNT Run и Build Battle можно запустить своим пати, не дожидаясь серверного ивента.

```
/tntrun party
/bb party
```

**Наград нет** — это игра на интерес. На весь сервер ничего не объявляется,
записаться могут только участники вашего пати. Хост может начать сразу через
`/tntrun skip` или `/bb skip`, не дожидаясь конца записи.

### Когда запустить нельзя

Арена у каждого режима одна на весь сервер, поэтому свой матч занимает то же место,
что и объявленный ивент. Отсюда ограничения:

- **за 30 минут до серверного ивента того же типа.** До TNT Run меньше получаса —
  свой TNT Run не запустить, а Build Battle можно. И наоборот
- пока идёт матч этого режима — серверный или чужого пати
- если кто-то из пати уже в другом ивенте или в дуэли
- нужно минимум **2 человека** из пати в сети
- на запуск действует кулдаун 10 минут

!!! note "Серверный ивент всегда важнее"
    Если свой матч затянулся до времени объявленного ивента, он остановится,
    и начнётся серверный. Пропустить ивент из-за приватной игры нельзя.

## Ад и Энд по расписанию

Порталы открыты не всегда. Сколько осталось — `/nethertime` и `/endtime`.
Об **открытии и закрытии Энда** сервер объявляет в общий чат, так что момент
не придётся угадывать.

## Час PvP

**Когда:** 20:00, длится час.

PvP включается **по всей карте**, включая территории городов. Спавн не затрагивается.
Хорошее время для набегов и плохое — для одиночных вылазок с ценным инвентарём.

## Рыбацкие турниры

Каждые **6 часов**, по 15 минут. Подробности: [Рыбалка](fishing.md#турниры).

## Ночная смена

После «Часа PvP» в 20:00 сервер не засыпает: с 00:30 до 07:30 идут боссы, Король горы
и лут-ивенты. Командных ивентов ночью нет — КБ, TNT Run и Build Battle требуют набора
участников, а ночью их обычно не набрать.

| Время | Ивент |
|---|---|
| 00:30 | Босс |
| 01:30 | Король горы |
| 02:15 | Лут-ивент |
| 03:00 | Босс |
| 06:15 | Король горы |
| 06:45 | Лут-ивент |
| 07:30 | Босс |

С 04:00 до 05:30 пусто намеренно: в 05:00 сервер уходит на ежедневный перезапуск.

Если в сети никого нет, ивент не запускается — мобы не будут висеть в мире до утра.

## Как не пропустить

- `/ivents` — расписание с обратным отсчётом, обновляется каждую секунду
- объявления в чате и в Discord-канале сервера
- клиент-мод NationRise показывает статус сервера в Discord Rich Presence
