# Города

Город — основа всего. Он даёт приват территории, банк, работы, здания, склад и место в нации.

## Создание

```
/t create <название>
```

Стоит **10 монет**. Чанк, в котором вы стоите, становится центральным.

**Ограничения при основании:**

- минимум **3 чанка** от чужой территории
- нельзя основать в мире спавна и в отключённых мирах

## Территория (чанки)

```
/t claim          приватить чанк, в котором стоите
/t unclaim        снять приват (возврат 50% цены)
/t map            карта окрестных чанков
```

Приват одного чанка — **1 монета**.

**Сколько чанков можно:**

```
8 (база) + 8 за каждого жителя + 8 за каждый уровень города выше первого
```

Город 3 уровня на 5 жителей: `8 + 40 + 16 = 64` чанка.

**Правила привата:**

- новый чанк должен **примыкать** к вашим
- нельзя приватить вплотную к чужому городу — нужен буфер в 1 чанк

## Уровни города

Уровней шесть. Каждый даёт +8 к лимиту чанков и открывает новые здания.
С **3 уровня** доступны [идеологии](ideology.md) и [религии](religion.md).

Повышение требует денег, ресурсов, жителей, построенных зданий, территории и возраста города —
это работа на весь город, а не на одного мэра.

**Полная таблица требований: [Уровни города](levels.md).**

```
/t levelup
```

## Жители и роли

```
/t invite <ник>     пригласить
/t kick <ник>       выгнать
/t leave            выйти из города
```

| Роль | Может |
|---|---|
| **Мэр** | всё: приват, банк, здания, война, роли, снос города |
| **Помощник** | приват, приглашения, склад, здания, таблички каторги |
| **Житель** | работать, пользоваться складом и зданиями, платить налог |

Назначение: `/t set assistant <ник>`.

## Спавн города

```
/t spawn          телепорт в город
/t set spawn      задать точку (мэр)
```

Телепорт с задержкой **3 секунды** — движение сбрасывает. Перезарядка 30 секунд.
Деньги за телепорт (если мэр включил плату) списываются **в момент телепорта**, а не заранее:
отменили — ничего не потеряли.

## Участки внутри города

Город можно нарезать на участки и раздать/сдать жителям — свои домики со своей защитой.

```
/plot info        что за участок под ногами
/plot claim       занять свободный участок
```

Управление — через здание **Бюро участков**.

## Аутпосты

Отдельный кусок территории вдали от основного города — шахта, порт, форпост.
Открывается кнопкой «Аутпосты» в `/t`.

## Склад

Общий склад города: 9 / 18 / 27 слотов по уровням здания «Склад».
Сюда же можно направить воронки и миньонов.

## Руины и снос

Не заплатили содержание — город становится **руинами** (защита снята), потом сносится.
Подробно: [Экономика → Содержание](economy.md#содержание-города).

Добровольно удалить город: `/t delete` (только мэр, подтверждение).

## Полезные команды

| Команда | Что делает |
|---|---|
| `/t` | главное меню города |
| `/t info` | сводка: уровень, банк, жители, чанки |
| `/t jobs` | работы и профессии |
| `/t build` | здания |
| `/t deposit <сумма>` | положить в банк |
| `/t withdraw <сумма>` | снять из банка |
| `/t set name <имя>` | переименовать (20 монет) |
| `/t restore` | восстановить из руин (50 райзиков) |
| `/tc <текст>` | чат города |

Полный список: [Справочник команд](commands.md).
