# Справочник команд

Почти всё есть в меню — команды знать необязательно. Но если удобнее так:

## Город

| Команда | Что делает |
|---|---|
| `/t` · `/town` | главное меню города |
| `/t create <имя>` | основать город (3 монеты) |
| `/t info` | сводка города |
| `/t claim` · `/t unclaim` | приватить / снять приват чанка |
| `/t map` | карта окрестных чанков |
| `/t invite <ник>` · `/t kick <ник>` | пригласить / выгнать |
| `/t leave` | выйти из города |
| `/t set assistant <ник>` | назначить помощника |
| `/t spawn` · `/t set spawn` | телепорт в город / задать точку |
| `/t deposit <сумма>` · `/t withdraw <сумма>` | банк города |
| `/t jobs` | работы и профессии |
| `/t build` | здания города |
| `/t set name <имя>` | переименовать (20 монет) |
| `/t set katorgachest` | привязать сундук каторги |
| `/t restore` | восстановить из руин (50 райзиков) |
| `/t fly` | полёт по своему городу (Архонт+) |
| `/tc <текст>` | чат города |
| `/plot` · `/pl` | участки внутри города |

## Нация

| Команда | Что делает |
|---|---|
| `/n` · `/nation` | меню нации |
| `/n create <имя>` | основать нацию (50 монет) |
| `/n invite <город>` · `/n join <нация>` | пригласить / вступить |
| `/n leave` · `/n kick <город>` | выйти / исключить |
| `/n rename <имя>` | переименовать (50 монет) |
| `/n capital <город>` | сменить столицу |
| `/n fly` | полёт по территории нации (Октавиан) |
| `/nc <текст>` | чат нации |

## Настройки и аккаунт

| Команда | Что делает |
|---|---|
| `/rp [full\|off]` | ресурспак |
| `/sb [menu]` | скорборд и его настройка |
| `/sit` | присесть (встать — прыжок или `/sit` ещё раз) |
| `/ptime <день\|ночь\|закат\|рассвет\|сброс>` | своё время суток (видите только вы) |
| `/pweather <ясно\|дождь\|сброс>` | своя погода (видите только вы) |
| `/image <ссылка> [ш] [в]` | картина по ссылке: один предмет, ПКМ по стене вешает целиком |
| `/ally` | показывать союзников по бою и пати в зелёной коже (вкл/выкл) |
| `/hpbar` | полоска в бою: здоровье противника или таймер боевого режима |
| `/sb list` · `/sb load <имя>` | готовые заготовки доски: pvp, pve, politmine, mini, travel, classic |
| `/sb save <имя>` · `/sb del <имя>` | сохранить свою доску под именем, чтобы её брали другие |
| `/tglink` · `/2fa <код>` | 2FA через Telegram |
| `/discordlink` | привязка Discord |
| `/dcchat` | скрыть/показать чат из Discord |
| `/free` | бесплатный кейс за клиент-мод |
| `/report <ник> <причина>` | пожаловаться на игрока |

!!! tip "Не помните команду"
    Откройте `/menu` — оттуда доступно почти всё.
