# Как редактировать вики

Страница для администрации проекта. Игрокам она не нужна.

## Что такое эта вики технически

Обычные текстовые файлы в формате **Markdown**, лежащие в папке `docs/`. Никакой базы данных,
никакой админки. Поправили файл — сайт пересобрался сам.

```
NationRise-Wiki/
├── docs/
│   ├── index.md          главная
│   ├── towns.md          города
│   ├── rules.md          правила
│   ├── assets/           картинки, скриншоты, логотип
│   └── SUMMARY.md        оглавление (для GitBook)
└── mkdocs.yml            настройки сайта и меню слева
```

---

## Способ 1 — прямо в браузере (проще всего)

1. Откройте репозиторий на GitHub.
2. Зайдите в `docs/`, нажмите на нужный файл.
3. Кнопка **карандаша** (Edit this file) справа сверху.
4. Правьте текст, снизу — **Commit changes**.
5. Через 1–2 минуты сайт обновится сам.

Так можно работать с телефона и не устанавливать вообще ничего.

## Способ 2 — локально

```bash
git clone <адрес репозитория>
cd NationRise-Wiki
py -3.13 -m pip install mkdocs-material
py -3.13 -m mkdocs serve
```

Откройте `http://127.0.0.1:8000` — сайт с **живой перезагрузкой**: сохранили файл,
страница в браузере обновилась сама. Закончили — `git add -A`, `git commit`, `git push`.

## Разметка: шпаргалка

### Текст

```markdown
**жирный**   *курсив*   `команда`   ~~зачёркнутый~~

# Заголовок страницы (один на файл)
## Раздел
### Подраздел
```

### Списки

```markdown
- пункт
- ещё пункт
  - вложенный

1. первый
2. второй
```

### Таблицы

```markdown
| Что | Сколько |
|---|---|
| Основание города | 3 монеты |
| Приват чанка | 1 монета |
```

Выравнивание столбца: `|---:|` вправо, `|:---:|` по центру.

### Ссылки

```markdown
[на другую страницу](towns.md)
[на раздел внутри страницы](economy.md#содержание-города)
[наружу](https://discord.gg/...)
```

Якорь раздела = заголовок строчными буквами, пробелы заменены на дефисы:
`## Содержание города` → `#содержание-города`.

### Картинки

Положите файл в `docs/assets/` и вставьте:

```markdown
![Меню города](assets/town-menu.png)
```

Подпись под картинкой:

```markdown
![Меню города](assets/town-menu.png)
/// caption
Главное меню города — команда `/t`
///
```

### Цветные плашки

```markdown
!!! note "Заголовок плашки"
    Текст с отступом в 4 пробела.

!!! tip "Совет"
    Зелёная плашка.

!!! warning "Внимание"
    Жёлтая.

!!! danger "Опасно"
    Красная.
```

### Блоки команд

Три обратных кавычки, внутри — команды:

````markdown
```
/t create <название>
```
````

### Вкладки

```markdown
=== "Через меню"
    Откройте `/t` и нажмите «Банк».

=== "Командой"
    `/t deposit 100`
```

## Как добавить новую страницу

1. Создайте файл в `docs/`, например `docs/minions.md`.
2. Начните с заголовка первого уровня: `# Миньоны`.
3. Добавьте страницу в меню — в `mkdocs.yml`, секция `nav:`:

```yaml
  - Занятия:
      - 🎣 Рыбалка: fishing.md
      - 🤖 Миньоны: minions.md      # ← новая строка
```

4. Если планируете переезд на GitBook — добавьте ту же строку в `docs/SUMMARY.md`.

---

## Что нельзя ломать

- **Отступы в `mkdocs.yml`** — только пробелы, никаких табов. Сломали отступ — сайт не соберётся.
- **Имена файлов** — только латиница, без пробелов: `town-levels.md`, а не `Уровни города.md`.
- **Ссылки при переименовании** — переименовали файл, поправьте ссылки на него в других страницах.

Если сборка упала, GitHub пришлёт письмо, а на вкладке **Actions** будет видно, в какой строке ошибка.

## Что обновлять при изменении баланса

Числа в вики взяты из `config.yml` плагина. Меняете баланс — пройдитесь по списку:

| Что поменяли | Какие страницы |
|---|---|
| Цены города, чанков, зданий | [Экономика](economy.md), [Города](towns.md), [Здания](buildings.md) |
| Содержание, налоги | [Экономика](economy.md) |
| Требования уровней города | [Уровни города](levels.md) |
| Расписание ивентов | [Ивенты](events.md) |
| Цены привилегий | [Привилегии](donate.md) |
| Лассо, сроки, выкупы | [Каторга](prison.md) |
| Эффекты идеологий и религий | [Идеологии](ideology.md), [Религии](religion.md) |
| Правила и наказания | [Правила](rules.md) |
