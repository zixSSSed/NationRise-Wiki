# Прочие механики

## Лифты

Табличка, на которую вы смотрите, превращается в лифт:

```
/lift
```

Дальше — прыжок вверх и присед вниз для перемещения между этажами.

## Порталы Ада и Энда

Открыты **по расписанию**, а не всегда:

```
/nethertime     сколько до открытия/закрытия Ада
/endtime        то же для Энда
```

Городам доступ дают здания **Адские врата** и **Врата Энда**.

## Уникальная Булава

На сервере может существовать **только одна** Булава. Как только её скрафтили,
рецепт закрывается для всех остальных. Урон ограничен потолком в 9.

## Скины предметов

Косметические скины, которые вешаются на предметы. Передаются и продаются как токены.

## Алкоголь и бочки

Варка напитков в бочках. Пьяный игрок начинает искажать речь в чате (со 2 уровня опьянения).

## Казино

Здание **Казино** открывает жителям `/casino` — игры на монеты.

## Задания

НПС заданий на спавне: ежедневные и еженедельные цели с наградами.
Раз в неделю объявляется **Госзаказ** — общая цель для всего сервера.

## Голограммы-топы

На спавне стоят топы по балансу, городам и нациям — обновляются автоматически.

## Карта BlueMap

Онлайн-карта сервера: границы городов, столицы наций (с короной), уровни городов
разными значками.

## Двухфакторная защита (2FA)

Защищает аккаунт от угона: даже зная пароль, зайти без подтверждения не выйдет.

### Способ 1 — из бота (основной)

Напишите нашему боту в Telegram или Discord:

```
/link <ваш ник> <ваш пароль>
```

Бот проверит пароль и отправит запрос **в игру**. Дальше зайдите на сервер —
в чате появится кнопка **[Подтвердить привязку]**, либо введите:

```
/linkconfirm
```

Запрос живёт **10 минут**. Если вы были не в сети, кнопка появится при следующем входе.

!!! danger "Пароля недостаточно — и это защита, а не неудобство"
    Привязка происходит только после подтверждения В ИГРЕ. Если вам пришёл запрос,
    а вы его не отправляли — значит кто-то знает ваш пароль.
    **Ничего не подтверждайте** и срочно смените пароль: `/changepassword`

### Способ 2 — из игры

Если удобнее начать с игры:

```
/tglink          получить код для Telegram-бота
/discordlink     то же для Discord
```

Команда выдаст шестизначный код — откройте бота, нажмите **Start** и пришлите этот код.

### После привязки

При входе с нового IP код приходит вам в личку боту, а в игре нужно ввести:

```
/2fa <код>
```

Доверенная сессия с того же IP запоминается на **12 часов**, чтобы не спрашивать каждый раз.

Отвязать: `/tglink unlink` или `/discordlink unlink`.
Потеряли доступ к боту — обратитесь к администрации, есть команда снятия привязки.

## Discord

Чат сервера продублирован в Discord-канал и работает в обе стороны: то, что пишут
в канале, видно в игре, и наоборот. Привязанный аккаунт показывается с вашим ником и аватаркой.

- скрыть у себя сообщения из Discord: `/dcchat`
- привязать аккаунт: `/discordlink`

В отдельном канале висит **эмбед со статусом сервера** — онлайн, TPS, адрес; обновляется сам.

## Клиент-мод NationRise

Необязательный мод: показывает сервер в Discord Rich Presence.
За установку — бесплатный кейс: `/free`.

## Скорборд

Боковая панель настраивается под себя:

```
/sb menu       выбрать строки, порядок и цвета
/sb            включить/выключить
```

## Голосование

```
/vote
```

Голос за сервер на мониторингах: **3 монеты + 3 райзика**. Награда приходит и в оффлайне —
получите при следующем входе.
