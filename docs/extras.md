# Прочие механики

## Лифты

Табличка, на которую вы смотрите, превращается в лифт:

```
/lift
```

Дальше — прыжок вверх и присед вниз для перемещения между этажами.

## Порталы Ада и Энда

Открыты **по расписанию**, а не всегда:

```
/nethertime     сколько до открытия/закрытия Ада
/endtime        то же для Энда
```

Городам доступ дают здания **Адские врата** и **Врата Энда**.

## Скины предметов

Косметические скины, которые вешаются на предметы. Передаются и продаются как токены.

## Алкоголь и бочки

Варка напитков в бочках. Пьяный игрок начинает искажать речь в чате (со 2 уровня опьянения).

Бочка — примерно **2×2×3 ступеней одной древесины** с табличкой `barrel` на них.
ПКМ по табличке открывает склад на 26 слотов. **5 минут = 1 год выдержки.**
Табличка у бочки одна: вторую на ту же бочку повесить нельзя.

Сколько ещё вариться в котле — покажут **часы**: возьмите их в руку и кликните по котлу.
Пишет число ингредиентов и оставшееся время. Что именно варится, часы не выдают.

Сусло дозревает до срока, указанного в рецепте: чем ближе к нему, тем больше звёзд,
а на полном сроке напиток получает максимум. Дальше выдержка не растёт, но и не портится —
**держать напитки в бочке можно сколько угодно**. Единственное условие — подходящая
древесина: в неподходящей бочке выдержка просто не идёт.

## Булава

Булава на сервере **одна** и не куётся. Она достаётся тому, кто **первым убьёт
Дракона Края**, — это реликвия, а не обычное оружие. Любые другие булавы
уничтожаются. Урон ограничен: больше **6,5 сердец** за удар она не наносит
ни в какой броне.

## Картины по ссылке

`/image <ссылка> [ширина] [высота]` — сервер скачает картинку и выдаст **один
предмет** на всю картину. Размер задаётся в блоках: `/image https://… 2 2` —
картина два на два.

Кликните правой по стене — картина развесится целиком, а блок, по которому вы
кликнули, станет её **левым нижним углом**. Нужен свободный прямоугольник нужного
размера и сплошная стена за ним. Удар по картине снимает её целиком и возвращает
предмет — по частям она не разбирается.

## Казино

Здание **Казино** открывает жителям `/casino` — игры на монеты.

## Задания

НПС заданий на спавне: ежедневные и еженедельные цели с наградами.
Раз в неделю объявляется **Госзаказ** — общая цель для всего сервера.

## Голограммы-топы

На спавне стоят топы — обновляются автоматически: по балансу, городам и нациям,
по райзикам, по убийствам, по рыбакам и по победам в войнах.

## Карта BlueMap

Онлайн-карта сервера: границы городов, столицы наций (с короной), уровни городов
разными значками.

## Двухфакторная защита (2FA)

Защищает аккаунт от угона: даже зная пароль, зайти без подтверждения не выйдет.

### Способ 1 — из бота (основной)

Напишите нашему боту в Telegram или Discord:

```
/link <ваш ник> <ваш пароль>
```

Бот проверит пароль и отправит запрос **в игру**. Дальше зайдите на сервер —
в чате появится кнопка **[Подтвердить привязку]**, либо введите:

```
/linkconfirm
```

Запрос живёт **10 минут**. Если вы были не в сети, кнопка появится при следующем входе.

!!! danger "Пароля недостаточно — и это защита, а не неудобство"
    Привязка происходит только после подтверждения В ИГРЕ. Если вам пришёл запрос,
    а вы его не отправляли — значит кто-то знает ваш пароль.
    **Ничего не подтверждайте** и срочно смените пароль: `/changepassword`

### Способ 2 — из игры

Если удобнее начать с игры:

```
/tglink          получить код для Telegram-бота
/discordlink     то же для Discord
```

Команда выдаст шестизначный код — откройте бота, нажмите **Start** и пришлите этот код.

### После привязки

При входе с нового IP код приходит вам в личку боту, а в игре нужно ввести:

```
/2fa <код>
```

Доверенная сессия с того же IP запоминается на **12 часов**, чтобы не спрашивать каждый раз.

Отвязать: `/tglink unlink` или `/discordlink unlink`.
Потеряли доступ к боту — обратитесь к администрации, есть команда снятия привязки.

## Discord

Чат сервера продублирован в Discord-канал и работает в обе стороны: то, что пишут
в канале, видно в игре, и наоборот. Привязанный аккаунт показывается с вашим ником и аватаркой.

- скрыть у себя сообщения из Discord: `/dcchat`
- привязать аккаунт: `/discordlink`

В отдельном канале висит **эмбед со статусом сервера** — онлайн, TPS, адрес; обновляется сам.

## Клиент-мод NationRise

Необязательный мод: показывает сервер в Discord Rich Presence.
За установку — бесплатный кейс: `/free`.

## Скорборд

Боковая панель настраивается под себя:

```
/sb menu       выбрать строки, порядок и цвета
/sb            включить/выключить
/sb reset      вернуть стандартный вид
```

### Готовые заготовки

Собирать доску с нуля не обязательно — можно взять готовую:

```
/sb list             посмотреть все заготовки
/sb load <имя>       взять заготовку себе
```

| Заготовка | Про что |
|---|---|
| `classic` | привычная доска NationRise |
| `pvp` | убийства, смерти, К/Д, серии, урон, пинг |
| `pve` | деньги, профессия, рыбалка, наигранное, территория, биом |
| `politmine` | ник, локация, деньги, блок нации и города |
| `travel` | координаты, биом, время, пинг |
| `mini` | четыре строки, ничего лишнего |

Загрузка перезаписывает вашу текущую раскладку. Вернуться к стандартной — `/sb reset`.

### Своя заготовка для других

Настроили удачную доску — сохраните её под именем, и её сможет взять кто угодно:

```
/sb save fe3st       выложить свою доску под именем fe3st
/sb del fe3st        убрать её
```

Дальше любой пишет `/sb load fe3st` и получает такую же. Чужую заготовку не перезаписать —
только автор (и администрация). Готовые заготовки сервера тоже не переписываются.

### Подстроки

Строки нации и города складываются в дерево: если поставить «Население» сразу под «Нацией»,
она нарисуется веткой — `┗ Население: 197`. Уберёте её из-под родителя — снова станет
обычной строкой со своей иконкой. Родителя нет (не состоите в нации) — подстрока просто
не показывается.

Рядом с ником можно показать остаток донат-привилегии: строка «Ник + дней привилегии»
рисует `Ник: fe3st (11 д.)`. У бессрочной привилегии и без неё хвоста нет.
