# NationRise — Вики

Исходники вики сервера. Страницы — обычный Markdown в `docs/`, так что переехать
с одного движка на другой можно в любой момент без переписывания текста.

## Что где

```
docs/              страницы вики (18 штук)
docs/SUMMARY.md    оглавление для GitBook
docs/assets/       логотип и фирменный CSS
mkdocs.yml         конфиг сайта (MkDocs Material)
.gitbook.yaml      конфиг для GitBook
```

## Вариант 1 — MkDocs Material (свой домен бесплатно)

Локальный просмотр:

```bash
py -3.13 -m pip install mkdocs-material
py -3.13 -m mkdocs serve -a 127.0.0.1:8010
```

Публикация на GitHub Pages настроена в `.github/workflows/deploy.yml` —
сайт пересобирается автоматически при каждом пуше в `master`.

**Свой домен:**

1. В настройках репозитория → Pages → Custom domain вписать `wiki.nationrise.ru`.
2. У регистратора домена добавить CNAME-запись: `wiki` → `<логин>.github.io`.
3. Дождаться выдачи сертификата (обычно минут 10-15) и включить Enforce HTTPS.

Стоимость: **0 ₽** сверх самого домена.

## Вариант 2 — GitBook

1. Зарегистрироваться на gitbook.com.
2. Создать организацию, в ней Space → **Sync with GitHub** → выбрать этот репозиторий.
3. GitBook подхватит `.gitbook.yaml`, `docs/SUMMARY.md` и все страницы.

**Свой домен** доступен начиная с плана Premium — **$65/мес** при годовой оплате.
На бесплатном плане адрес будет вида `<организация>.gitbook.io/<space>`.

!!! note "Про плашки-подсказки"
    Блоки `!!! note` / `!!! warning` — синтаксис MkDocs. GitBook их не понимает,
    ему нужны `{% hint %}`. Конвертация делается скриптом за пару минут —
    просто скажите, если переезжаете на GitBook.

## Как редактировать

Правьте `.md` файлы и коммитьте. Новая страница:

1. создать файл в `docs/`
2. добавить в `nav:` в `mkdocs.yml`
3. добавить в `docs/SUMMARY.md`

## Что держать в актуальном состоянии

Числа в вики взяты из `config.yml` плагина на момент написания. Если меняете баланс —
проверьте эти страницы:

| Что поменяли | Страница |
|---|---|
| цены города/чанков/зданий | `economy.md`, `towns.md`, `buildings.md` |
| содержание, налоги | `economy.md` |
| расписание ивентов | `events.md` |
| цены привилегий | `donate.md` |
| лассо, сроки, выкупы | `prison.md` |
| эффекты идеологий/религий | `ideology.md`, `religion.md` |
