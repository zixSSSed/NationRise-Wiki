# Какие скриншоты нужны для вики

Список для владельца. Снимайте **в игре с включённым ресурспаком** — иначе вместо иконок
будут пустые квадратики.

## Как снимать

- **Разрешение:** окно 1920×1080, GUI Scale 3 (F3 → настройки → Video → GUI Scale).
- **Меню:** нажмите **F1** перед снимком — уберётся хотбар и лишний интерфейс.
- **Формат:** PNG. Скриншот целого экрана, обрезать не надо — обрежу сам.
- **Имя файла:** как в списке ниже, латиницей. Кидайте пачкой, я разложу и вставлю.
- Не снимайте свой ник в чате, если не хотите его в вики.

## Обязательные (18 штук)

### Меню и интерфейс

| Файл | Что снять | Как получить |
|---|---|---|
| `town-menu.png` | главное меню города целиком | `/t` в своём городе |
| `town-buildings.png` | меню зданий с ценами | `/t build` |
| `town-jobs.png` | меню работ | `/t jobs` |
| `town-levelup.png` | окно повышения уровня с требованиями | `/t` → «Уровень города» |
| `donate-menu.png` | витрина привилегий | `/donate` |
| `kits-menu.png` | меню китов | `/kit` |
| `shop-menu.png` | магазин | `/shop` |
| `auction.png` | аукцион с несколькими лотами | `/ah` (выставьте 3-4 лота заранее) |
| `fish-journal.png` | журнал рыбака | `/fish` → журнал |
| `events-menu.png` | расписание ивентов | `/ivents` |

### Игровой мир

| Файл | Что снять | Как получить |
|---|---|---|
| `spawn.png` | общий вид спавна | встаньте так, чтобы попали НПС и кейсы |
| `city-view.png` | красивый город с высоты | любой развитый город, лучше на закате |
| `bluemap.png` | карта с границами городов | откройте BlueMap в браузере, зумните на скопление городов |
| `katorga.png` | каторга с пленным | шахта, пленный игрок, привязанный сундук в кадре |
| `war-flag.png` | установленный военный флаг | во время войны или тестом |
| `scoreboard.png` | боковой скорборд крупно | подойдёт любой скрин, где панель читается |
| `chat.png` | чат с плашками рангов и городами | пара сообщений от игроков с разными рангами |
| `boss.png` | босс-ивент в разгаре | любой из трёх боссов, желательно с толпой |
